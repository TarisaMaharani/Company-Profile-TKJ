BAB 1 • MATERI

Kabel LAN & Crimping RJ-45

    💡 Tips Belajar dari BUNBYTE:
    LAB PRAKTIK 1 • KABEL JARINGAN

    🔌 Simulasi Crimping Kabel LAN (RJ-45)

    Mode Straight (Standar T568B): Susun 8 warna kabel dari Pin 1 sampai Pin 8 untuk menghubungkan PC ke Switch/Router.
    Konektor RJ-45 • Pin 1 sampai Pin 8 (Klik pin untuk mencabut warna)
    📟 Indikator Lampu LAN Tester (Pin 1 – 8)
    Lampu hijau akan menyala berurutan jika hasil crimping benar!
    LAB PRAKTIK 2 • ADMINISTRASI SERVER

    🐧 Mini Terminal Ubuntu Server

    Ketik perintah dasar Linux jaringan di bawah (atau klik tombol pintasan) untuk melihat output server!

    siswa@tkj-playground:~$ (Ubuntu 24.04 LTS)
    Selamat datang di Lab Terminal Linux TKJ PLAYGROUND! Ketik perintah: help, ip a, ping 8.8.8.8, systemctl status apache2, ls -la, atau clear.
