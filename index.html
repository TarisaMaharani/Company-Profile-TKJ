    SIMULASI INTERAKTIF • LEARN BY DOING

    Practice Lab TKJ

    Praktikkan langsung simulasi jaringan, subnetting IPv4, crimping UTP, koding web, troubleshooting, dan CLI MikroTik.

    "Yuk, kita coba praktik bersama!"

    A. Network Simulator (Star, Bus, Ring)

    Tambah perangkat PC, Router, Switch, atau Server, hubungkan dengan kabel virtual, lalu uji topologinya.

    Informasi Perangkat

    Klik perangkat di canvas untuk melihat fungsi dan detailnya, atau aktifkan Mode Kabel lalu klik dua perangkat untuk menghubungkan.

    B. IP Address Configuration & Subnetting Lab

    Masukkan IPv4, Subnet Mask atau CIDR (/8 sampai /30), serta Default Gateway untuk menghitung subnet secara matematis.

    C. Cable Wiring Lab (RJ-45 Straight & Crossover)

    Pilih standar & jenis kabel, lalu seret (drag & drop) atau klik 8 warna kabel ke pin RJ-45 (Pin 1–8).

    KONEKTOR RJ-45 • PIN 1 → PIN 8 (Klik pin untuk mengosongkan)

    D. Web Coding Playground (HTML & CSS Live Preview)

    Tulis atau edit kode HTML dan CSS lalu klik Run untuk melihat hasil langsung di sandbox preview.

    Live Preview (Sandboxed)

    E. Network Troubleshooting Lab

    Analisis kasus gangguan jaringan, pilih pemeriksaan yang tepat, dan tentukan solusi terbaik.

    Latihan perintah dasar RouterOS: IP Address, DHCP Client/Server, Default Route/Gateway, dan pemeriksaan konfigurasi.
